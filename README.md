# Tehnici computerizate în aparatele electromedicale

Materiale didactice – Școala postliceală, calificarea *Tehnician aparate electromedicale*, anul II, modulul 16 (60 ore).

- `prezentare.html` – prezentarea modulului (19 slide-uri). Se deschide în browser; navigare cu ← → / spațiu, **F** ecran complet, **P** tipărire/PDF.
- `teme.html` – fișele celor 6 teme de lucru, grilele de evaluare și bibliografia completă.

Fișierele sunt de sine stătătoare (fără biblioteci externe) și pot fi publicate direct cu GitHub Pages.
